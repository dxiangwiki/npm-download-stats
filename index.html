NPM Package Historical Total Download Query

Query cumulative historical downloads of npm packages, fetch data from official npm API, pure frontend, no backend required.

Ready. Enter package name and click Query.

Notes & Limitations

• Data source: official npm api.npmjs.org & registry.npmjs.org

• Statistics start from the first publish date of the package, but npm download metrics are only available from ~2015.

• Download count ≠ unique users. CI/automated repeated installs will be counted multiple times.

• Network: mainland China users may experience timeout when accessing npm official API.

• Author batch query: npm registry API returns public packages only, rate limit may cause partial failures.
